# 🏛️ CIO TD Monitor

## Version web déployable

Le dépôt contient maintenant une interface web autonome avec watchlist éditable, univers d'indices,
matières premières, devises, taux, données Yahoo Finance, résumé des signaux, alertes locales et
export CSV. Le point d'entrée pour Render est `index.html` servi par `server.py`.

Une version Streamlit est également disponible dans `streamlit_app.py` pour un déploiement gratuit
sur Streamlit Community Cloud, sans carte bancaire.

Voir [DEPLOIEMENT.md](./DEPLOIEMENT.md) pour publier l'application.

Outil d'analyse de l'épuisement des tendances (TD Sequential) pour Luc Verville.
- **Setup (9)** : Phase de préparation.
- **Countdown (13)** : Signal de retournement.
